# Ideas

这个目录不是默认启动上下文，也不是当前任务列表。

它的作用更像产品经理的仓库内工作区：

- 平时随手记下外部看到的好产品、好交互、好仓库、好念头
- 把值得长期讨论和调研的话题单独沉淀下来
- 等某个想法真的要做时，再进入执行计划和当前任务

## 什么时候读

只在下面这些场景再读：

- 你主动说“我们来看 ideas”
- 你刚补充了新的想法
- 我们在讨论产品方向、长期规划、外部参考或实验路线

## 这两个文件怎么分工

- [DAILY_CAPTURE.md](DAILY_CAPTURE.md)
  放每天随手记下来的灵感、链接、观察、半成品念头。

- [LONG_TERM_TOPICS.md](LONG_TERM_TOPICS.md)
  放那些需要持续讨论、反复调研、暂时没有结论的问题。

## 和现有文件的边界

- `ideas/*`
  先记录，先发散，不要求马上收敛。

- `.tasks/current.md`
  只放已经决定在做的事情。

- `.claude-summary.md`
  只放会影响项目阶段、产品方向和长期路线图的内容。

- `research/templates/AI_EXECUTION_PLAN_TEMPLATE.md`
  当某个想法已经决定进入实现时，再写执行计划。
