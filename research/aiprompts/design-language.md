# VoxFlame Design Language

> 这是 `VoxFlame` 当前页面改版时默认要先看的视觉与交互语言入口。

## 1. 设计目标

`VoxFlame` 不是宣传页产品，也不是炫技 demo。

页面首先要让用户感觉：

1. 我被接住了
2. 我知道下一步点哪里
3. 系统不会抢走我的主导权

## 2. 核心气质

1. 干净
   - 页面先突出一个动作，不同时争抢多个视觉中心
2. 可信
   - 主表面默认实体底色，不靠大面积半透明和模糊制造“高级感”
3. 低压力
   - 文案像伙伴，不像系统提示或营销口号
4. 中文优先
   - 避免英文产品式 tracking、过重标签感和过多技术名词
5. 任务优先
   - 首页是任务入口；工作台是操作界面；档案页是准备页面

## 3. 页面级规则

### 首页

1. 首屏优先回答“我现在能做什么”
2. 优先承接高压场景：面试、工作协作、医疗沟通、陌生人求助
3. 不先解释模型、架构、字幕或愿景

### 沟通工作台

1. 先给场景、starter phrase 和大动作区
2. 不要默认把消息气泡墙当成主角
3. 保持 glanceable，重要状态一眼能看懂

### 练习工作台

1. 目标句和反馈是主角
2. 用户录完一屏内就知道系统听到了什么、下一步怎么练
3. 上传授权永远是次级动作

### 沟通档案

1. 不做报表中心
2. 先回答“下次怎么更好开口”
3. 高频表达、最近卡点、下一次准备优先于统计图

## 4. 视觉规则

1. 背景只做弱氛围，不做喧宾夺主的渐变分割
2. 卡片优先实体白或浅中性色
3. 强调色以温暖中性色系为主，重点动作要清楚但不刺眼
4. 大标题短句化，避免品牌宣言式长句堆叠
5. 信息分组靠间距和层级，不靠复杂装饰线

## 5. 交互规则

1. 用户始终可以打断、覆盖和改写 agent
2. 动效只服务状态切换，不做表演型动画
3. 重要按钮文案用任务语言，例如“进入沟通模式”“练习表达”
4. 不让用户先配置大量参数再开始核心任务

## 6. 风格判断题

如果一个设计方案满足以下任一情况，默认需要重做：

1. 更像说明书，而不是工作台
2. 更像聊天 demo，而不是沟通辅助工具
3. 更像品牌页，而不是任务入口
4. 用户必须先读很多字，才知道下一步点哪里
5. 界面让用户感觉“我被评估”，而不是“我被支持”
