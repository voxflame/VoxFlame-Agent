## 2. Web 真实账号与浏览器

### 2.1 采集前

- [ ] 使用真实测试账号登录，确认训练同意已生效。
- [ ] 打开 `/contribute/topic/<topicId>`，确认只显示当前目标句。
- [ ] 未勾选“环境安静”或“麦克风位置稳定”时，录音按钮不可开始，并显示可操作提示。
- [ ] 选择“首轮基线 / Anchor / 连续朗读 / 自然表达”之一，开始录音后题目标识不再变化。

### 2.2 录音、回放、撤回

- [ ] 允许浏览器麦克风，录一条完整句；页面显示实时识别结果。
- [ ] 停止后确认目标文本与系统听到的文本分开显示。
- [ ] 回放音频，确认有声、无明显削波或近静音。
- [ ] 点击“不收录/撤回”，确认本机队列和云端贡献均被移除，页面提示撤回成功。
- [ ] 录音过程中切换网络为离线；停止后确认录音进入本机队列，不丢失。
- [ ] 恢复网络或切换页面可见，确认队列自动补传并收到 upload receipt。
- [ ] 若浏览器输入不是 PCM WAV，确认原格式母版仍在本机/受控存储，WAV 只是训练副本且 recording ID 一致。

### 2.3 证据

记录：浏览器版本、页面截图、控制台无未处理错误、上传 receipt 的 recording ID（仅内部追踪，不对外发布）。

## 3. Android 真机

- [ ] 首次进入录音页仅请求麦克风权限；拒绝后显示原因，已有本机录音不被删除。
- [ ] 勾选环境、距离、训练授权；未全部勾选时“开始说”不能录音。
- [ ] 选择采集计划和公共题库/自定义材料，确认目标文本显示正确。
- [ ] 在线录一条：停止后本机 queue 有记录，可回放，上传状态最终为 uploaded/indexed。
- [ ] 在线录音开始后关闭网络：录音仍能开始/停止，queue 状态为 local_only/upload_pending。
- [ ] 记录原生录音文件格式；确认上传或格式转换不会覆盖本机母版。
- [ ] 恢复网络：自动重试，上传完成后显示 receipt；重复重试不得生成重复 manifest 条目。
- [ ] 对已上传条目执行“撤回并删除”，确认云端贡献、manifest 条目、音频对象和本机文件均移除。
- [ ] 连接蓝牙/有线麦后拔出，确认安全回退到手机内置麦，不崩溃、不误录静音。

证据：机型/系统版本、App 版本、queue 状态截图、receipt、撤回响应、异常发生时间。

## 4. iOS 真机与签名

- [ ] Account Holder/Admin 已创建 Bundle ID、Distribution Certificate 和 Provisioning Profile。
- [ ] `npm run build:ios:preview` 成功并保留 EAS build URL。
- [ ] TestFlight 或开发设备安装成功，Bundle ID 为 `org.voxflame.mobileworkbench`。
- [ ] 首次录音授权、录音、停止、回放、上传 receipt 全部成功。
- [ ] 关闭网络后录音仍保存在本机；恢复网络后自动补传。
- [ ] 切换有线/蓝牙输入并断开，确认路由回退和录音状态可见。
- [ ] 执行撤回，确认云端和本机均不再保留该条样本。

未完成签名或真机安装时，iOS 项目状态必须保持 `pending`，不能写成“已上线”。

## 5. P0 硬件 A/B

对同一 speaker、同一目标句、同一环境分别使用手机内置麦和候选设备，各录至少 10 条：

- [ ] 记录输入路由、距离/佩戴方式、连接建立时间和断连恢复时间。
- [ ] 比较近静音、削波、断续、目标文本对齐和陌生人听懂结果。
- [ ] 记录用户完成开始/停止/回放/撤回所需帮助次数。
- [ ] 只有候选设备在可理解性、稳定性和用户负担上出现可重复净增益，才进入下一轮供应商询价；否则保留手机内置麦基线。

## 6. 结论规则

| 状态 | 规则 |
| --- | --- |
| `pass` | 该平台/设备所有必选项有证据，且无 Critical 失败 |
| `conditional` | 只有明确记录的非关键问题，给出 owner、修复日期和回归步骤 |
| `pending` | 缺真实账号、签名、真机、硬件或部署证据 |
| `fail` | 录音丢失、目标/实际文本错位、撤回失败、重复 manifest 或严重隐私泄露 |

任何一项 `pending` 或 `fail` 都不能宣称 Web/Android/iOS 全平台完成或已上线。
